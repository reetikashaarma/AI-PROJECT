COMPLETE PROJECT SETUP — WINDOWS + VS CODE

1. Extract AI_Sales_Analytics_Complete.zip.
2. Open the extracted AI_Sales_Analytics_Complete folder in VS Code.
3. Open Terminal > New Terminal.
4. Run these commands one by one:

   py --version
   py -m venv .venv
   .venv\Scripts\activate
   python -m pip install --upgrade pip
   python -m pip install -r requirements.txt

5. Run automated tests:

   python -m pytest -q

6. Start the app:

   streamlit run app.py

7. In the sidebar, select Upload Dataset.
8. Upload your Superstore Excel file.
9. Confirm that Order date is mapped to Order Date and Sales / revenue to Sales.
10. Click Validate and prepare dataset.

IMPORTANT:
- If `py` is not recognized, install Python 3.10+ from https://www.python.org/downloads/ and enable Add Python to PATH.
- If PowerShell blocks activation, run:
  Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
  then activate again.
- Do not upload private sales data to GitHub.
- The included data/sample_sales.csv is a small synthetic example for a quick test.
